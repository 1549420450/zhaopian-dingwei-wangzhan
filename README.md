# 牵手物业品质考核地图

静态网站，可部署到 GitHub Pages。index.html 在仓库根目录；Pages 选择默认分支的 /(root)。

隐私：仓库不包含真实检查照片、位置记录或识别结果。照片识别在浏览器本地完成，默认不长期保存；使用者可勾选本机保存，也可清空记录。地图接入完成后将默认开启在线地图与乡镇查询，并会把经纬度发送给高德；使用者可取消勾选关闭。手动打开高德位置链接也会发送所选位置，照片文件不会发送。识别组件从 CDN 下载，识别照片原文件不会发送到识别服务器。

地图：已预置 Web 端 Key。地图显示及自动乡镇查询通过高德安全代理接入，代理地址位于 map-config.js；安全密钥仅保存在代理服务器，不提交到公开仓库。地图尚未连接时，可以识别经纬度、手动确认乡镇、导出表格，并在记录中打开高德位置。Key 的域名白名单应添加实际 GitHub Pages 域名。

公开分享仅分享网站工具，每位访问者有各自的浏览器数据，无法查看他人的检查照片。浏览器本机保存不提供额外加密；共用电脑使用后可清空记录。

第三方组件：exifr 7.1.3、Tesseract.js 6.0.1。地图：高德地图 JS API 2.0 / URI API。

地址查询：高德安全代理在部分网络下被托管平台拦截时，使用 OpenStreetMap Nominatim 作为备用，每秒最多一次查询。只有经纬度会发送到地址服务，照片文件仍在本机处理。
